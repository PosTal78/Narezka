# Озвучка и сегменты

Первый функциональный этап использует Edge TTS. Один текстовый сегмент всегда создаёт один MP3: `audio/001.mp3` … `audio/N.mp3`. Сегмент может содержать одно или несколько предложений.

## Ввод сценария

Пользователь может вставить текст, импортировать `.txt`, очистить текст и сохранить его в проект. Если проекта нет, перед первым сохранением приложение запрашивает папку и название нового проекта. Текст сохраняется автоматически после подтверждённого изменения.

## Режимы сегментации

| Режим | Правило |
| --- | --- |
| По строкам | Значение по умолчанию. Каждая непустая строка — сегмент; пунктуация внутри строки не дробит её. |
| По предложениям | Каждое отдельное предложение — сегмент. |
| По абзацам | Каждый непустой абзац — сегмент; пунктуация внутри не дробит его. |

Заголовки могут быть исключены из озвучки. Пользователь видит ID, текст и статус каждого сегмента, может редактировать или удалить его, объединить с соседним либо разделить на две или несколько частей. После таких операций сегменты становятся источником актуального сценария, а основной текст собирается из них.

Повторная сегментация при существующем списке требует подтверждения. Готовый MP3 сохраняется только для сегмента с точно тем же текстом и настройками TTS; аудио изменённых, разделённых и объединённых сегментов получает статус «устарело». MP3 удалённых сегментов не перезаписываются при перенумерации, а переносятся в `audio/retired/`.

## Настройки и генерация

Пользователь выбирает язык, голос, скорость, громкость и pitch; короткое тестовое аудио проверяет выбор до кнопки «Озвучить всё». Кнопка «Применить настройки» сохраняет их для всего проекта. Если уже есть готовые MP3, приложение заранее объясняет, что они останутся на диске, но станут устаревшими; переозвучка не запускается сама. Для каждого сегмента сохраняются использованные настройки. «Озвучить всё» создаёт только отсутствующие или устаревшие MP3; отдельная команда полной перегенерации требует подтверждения и заменяет все неисключённые MP3.

Если текст вставлен или импортирован, но ещё не разбит на сегменты, при смене проекта или закрытии приложения пользователь выбирает: разбить и сохранить, не сохранять или отменить действие.

После успешного создания MP3 сервис вызывает `ffprobe` и получает длительность. Только затем файл помечается готовым и его метаданные сохраняются в `project.json`. Сбой генерации или анализа длительности должен показать понятный статус и причину у конкретного сегмента, не записывать фиктивную длительность и не останавливать обработку остальных сегментов.

## Прослушивание и перегенерация

Для сегмента доступно прослушивание готового MP3. Перегенерация заменяет только этот файл, повторно вызывает `ffprobe` и обновляет только его статус, настройки, путь и длительность. Остальные файлы и сегменты не меняются.
