# Будущий видеоконвейер

Эти возможности не реализуются до полной проверки этапа 1.

```text
source video
↓
Import and media metadata
↓
Subtitle import or local Whisper
↓
Scene Detection
↓
Video Index (transcript + key frames + local embeddings)
↓
Scene Matching
↓
Timeline
↓
FFmpeg Export
```

## Этап 2: видео, субтитры, сцены

Приложение импортирует `.mp4` или `.mkv` и по умолчанию сохраняет ссылку на исходный файл, показывает имя, длительность, разрешение, FPS и простой проигрыватель. Если файл по сохранённой ссылке недоступен, приложение требует повторно выбрать его и не подменяет источник автоматически. Субтитры берутся из `.srt`/`.vtt` либо создаются локальным Whisper. Результаты: `analysis/transcript.json`, `analysis/subtitles.srt`.

PySceneDetect/OpenCV формируют `analysis/scenes.json` с идентификаторами и таймкодами начала/конца. Весь фильм заранее на клипы не режется.

## Этап 3: анализ и подбор

Индекс сцены объединяет текст транскрипта, ключевые кадры, визуальное описание, персонажей/объекты и локальные embeddings. Для аудиосегмента ищутся один или несколько отрезков фильма с учётом смысла, субтитров, визуального содержимого и хронологии. Поиск предпочтительно продолжает линию оригинала, но может выбрать немного более ранний подходящий момент.

Каждое совпадение имеет confidence. Низкие значения попадают в «Требует проверки»; пользователь может посмотреть и заменить результат. Длинный аудиосегмент может получить несколько последовательных видеофрагментов.

## Этап 4: timeline и экспорт

Timeline — не видеоредактор, а простой список `audio segment | video fragments`. Пользователь прослушивает, просматривает, меняет таймкоды и состав фрагментов. Автоматический монтаж подбирает последовательные фрагменты на всю длительность аудиосегмента и подрезает последний фрагмент точно по длительности озвучки, не меняя скорость видео. FFmpeg создаёт `export/final.mp4` в Original/1080p/720p и Original/30/60 FPS. Оригинальный звук фильма по умолчанию выключен; фоновый тихий режим — будущее расширение.
