# Переносимый выпуск Windows

Готовый выпуск — папка `portable/` и архив `Narezchik-portable.zip` рядом с ней. Запускайте только `portable/Narezchik.exe`: на компьютере пользователя не требуются Python, FFmpeg или установленные библиотеки видеоанализа.

```text
portable/
├── Narezchik.exe
├── tools/ffmpeg/          # ffmpeg.exe и ffprobe.exe
└── data/
    ├── projects/          # предлагается по умолчанию при создании проекта
    ├── models/whisper/    # модели загружаются сюда при первом использовании
    ├── cache/
    └── logs/
```

## Сборка на Windows

В папке исходников на D: подготовьте `.venv` с `.[dev,video,matching]`. Полный FFmpeg должен содержать `ffmpeg.exe` и `ffprobe.exe`; по умолчанию сценарий берёт их из `%LOCALAPPDATA%\Narezchik\tools\ffmpeg`.

Для GPU-сборки перед упаковкой запустите `scripts/enable_cuda.ps1`. Скрипт устанавливает официальный CUDA 12.8 wheel PyTorch; без него приложение сохраняет рабочий CPU-режим, но анализ кадров будет существенно медленнее.

Сценарий перенаправляет служебный кэш PyInstaller в `.scratch/` на D:. Готовое приложение не использует ни `.venv`, ни кэш pip. `.venv/Scripts/narezchik.exe` — только технический запуск исходников.

Перед заменой приложения сборщик проверяет, что в готовую папку вошли VAD-модель `faster-whisper`, CTranslate2 и CUDA-библиотеки. Если хотя бы один из этих файлов отсутствует, сборка завершается с ошибкой и не заменяет рабочую версию. При запуске локальной расшифровки приложение добавляет `torch/lib` в поиск DLL, поэтому CTranslate2 может использовать поставляемые CUDA-компоненты.

```powershell
.\scripts\build_portable.ps1
```

Чтобы указать другой источник FFmpeg или папку portable-приложения:

```powershell
.\scripts\build_portable.ps1 -FfmpegPath 'D:\Tools\ffmpeg' -OutputRoot 'D:\Releases'
```

Не добавляйте пользовательские проекты и модели Whisper в компактный архив. При первой расшифровке faster-whisper скачает выбранную модель в `portable/data/models/whisper`; дальнейшая расшифровка использует её без сети. Edge TTS всегда требует интернет. При пересборке заменяются только EXE, `_internal/` и `tools/`; `portable/data/` сохраняется.

Whisper сначала использует NVIDIA GPU, когда CUDA полностью доступна. Если драйвер видит видеокарту, но отсутствуют её вычислительные библиотеки (например, `cublas64_12.dll`), приложение автоматически продолжит расшифровку на CPU. Это медленнее, но не является ошибкой. Предупреждение Hugging Face о недоступных symlink также безопасно: кэш работает без них, но может занять больше дискового пространства.
