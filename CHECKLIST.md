## Product

| Поле | Значение |
| --- | --- |
| Название | Narezchik |
| Назначение | Локальное создание видеопересказов фильмов и сериалов: от сценария и озвучки до подбора кадров и экспорта. |
| Операционная система | Windows — первый целевой вариант. |
| Основной пользовательский сценарий | Пользователь создаёт проект, готовит сценарий и озвучку, добавляет фильм, получает и проверяет подбор кадров, затем экспортирует ролик. |

## Capabilities

Состояния: `active` — доступно и должно работать; `planned` — запланировано; `deferred` — сознательно отложено; `absent` — не входит в продукт. Возможность без строки считается `absent`.

| Возможность | Состояние | Примечание |
| --- | --- | --- |
| Project management | active | Локальный формат проекта и постоянная панель проекта задокументированы; при первом сохранении без проекта запрашиваются папка и название; UI создаётся в этапе 1. |
| Script import | active | Ручной ввод и импорт `.txt`. |
| Text segmentation | active | По строкам (по умолчанию), предложениям и абзацам; с редактированием, объединением и разделением. |
| Edge TTS | active | Голос, язык, скорость, громкость, pitch, тестовое прослушивание и обработка очереди с изолированными ошибками. |
| Audio regeneration | active | Выбранный сегмент и отдельная подтверждаемая полная перегенерация; актуальные MP3 не перезаписываются массовой озвучкой. |
| FFmpeg integration | active | `ffprobe` для длительности в этапе 1; FFmpeg-экспорт позднее. |
| Video import | planned | `.mp4`/`.mkv`, ссылка на источник по умолчанию, метаданные и простой проигрыватель. |
| Whisper transcription | planned | Локальные субтитры и транскрипт. |
| Scene detection | planned | PySceneDetect/OpenCV, сохранение таймкодов. |
| Scene matching | planned | Подбор одного или нескольких фрагментов на аудиосегмент и confidence. |
| Timeline | planned | Простой редактируемый список, не аналог видеоредактора. |
| Video export | planned | FFmpeg в `export/final.mp4`. |
| Local AI | planned | Локальные embeddings и vision-модели для анализа и подбора. |
| ElevenLabs | deferred | Дополнительный провайдер в будущем. |
| OpenAI API | deferred | Дополнительный провайдер в будущем. |
| Gemini API | deferred | Дополнительный провайдер в будущем. |
| Accounts | absent | Нет учётных записей. |
| Payments | absent | Нет платежей. |
| Cloud backend | absent | Приложение работает локально. |
| Database server | absent | Состояние хранится в файлах проекта. |
| Mobile app | absent | Не входит в текущий объём. |

## Текущие ограничения

- Платные API не нужны для основной работы.
- Не начинать этапы 2–5, пока этап 1 не пройдёт тесты и пользовательский сценарий.
- После реализации проверять тесты, запуск desktop-приложения и затронутый пользовательский сценарий.
