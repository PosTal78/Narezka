# Принципы разработки

Пользователь описывает, **что** должно происходить. AI-агент самостоятельно определяет, **как** реализовать это технически.

Не спрашивайте пользователя, какую библиотеку, паттерн, класс или внутреннюю структуру данных выбрать, если это можно безопасно решить по контексту проекта. Спрашивайте только тогда, когда выбор заметно меняет поведение продукта или пользовательский опыт.

Перед изменением изучайте существующий код и документацию. Делайте наименьшее ясное изменение, которое решает задачу. Проверяйте результат и не считайте работу завершённой, пока основной пользовательский сценарий не подтверждён.
