# PRD — Narezchik

## 1. Назначение

Narezchik — локальная desktop-программа для автоматического создания видеопересказов фильмов и сериалов. Целевой поток: сценарий → TTS-озвучка → анализ исходного фильма → подбор фрагментов под озвучку → монтаж → готовое видео.

Программа модульная: в будущем тот же подход может применяться к стримам, YouTube-видео, боям и другому длинному видеоконтенту. В первой версии приоритет — понятная функциональность и скорость работы, а не сложный дизайн, анимации или лишние экраны.

## 2. Продуктовые принципы

- Все проекты и результаты хранятся локально; пользователь не редактирует `project.json` вручную.
- Основной режим не требует платных API: Edge TTS (или локальный TTS в будущем), локальный Whisper, FFmpeg, PySceneDetect/OpenCV и локальные модели.
- Платные провайдеры (ElevenLabs, OpenAI, Gemini и другие) могут появиться позднее как дополнительные варианты.
- Выполненные дорогие операции повторно не запускаются без необходимости: состояние и кэш сохраняются в папке проекта.
- Интерфейс имеет постоянную панель проекта и вкладки «Озвучка», «Видео», «Подбор кадров», «Монтаж», «Экспорт».

## 3. Проекты

В верхней панели постоянно показываются название текущего проекта и действия: «Выбрать проект», «Новый проект», «Открыть папку проекта». Если пользователь выполняет первое действие, требующее сохранения, без выбранного проекта, приложение показывает диалог выбора папки и названия нового проекта; неявно папку не создаёт.

Каждый проект хранится в отдельной папке по формату `docs/PROJECT_FORMAT.md`. `project.json` создаётся и обновляется программой как внутреннее состояние.

## 4. Этап 1 — озвучка сценария

Первая реализуемая вкладка — «Озвучка».

### Сценарий и сегменты

Пользователь может вставить сценарий вручную, загрузить `.txt`, очистить текст и сохранить его в проект. После импорта содержимое файла показывается в большом текстовом поле. После ручного изменения, разделения или объединения сегментов именно список сегментов является актуальным сценарием, а содержимое основного текстового поля собирается из него.

Перед первой генерацией программа делит текст на сегменты. Поддерживаются режимы:

- по строкам — по умолчанию: каждая непустая строка является сегментом, независимо от числа предложений;
- по предложениям — каждое предложение является сегментом;
- по абзацам — каждый непустой абзац является сегментом.

В режимах строк и абзацев знаки препинания внутри сегмента не дробят его. Заголовки сценария пользователь при необходимости может исключить из озвучки.

Список сегментов отображает ID, текст, статус, прослушивание, перегенерацию и удаление. Пользователь может изменить текст, разделить сегмент на несколько частей или объединить его с соседним сегментом. Повторная сегментация после существующих сегментов требует подтверждения: аудио сохраняется только у сегментов с точно тем же текстом и настройками TTS, а остальные помечаются устаревшими.

### Edge TTS

Пользователь выбирает язык, голос, скорость, громкость и pitch; до массовой генерации доступно тестовое прослушивание короткой фразы. «Озвучить всё» создаёт один MP3 на каждый отсутствующий или устаревший неисключённый сегмент: `001.mp3` … `N.mp3`; готовые актуальные MP3 не меняет. Для замены всех аудиофайлов предусмотрена отдельная подтверждаемая команда полной перегенерации.

После генерации длительность каждого файла определяется через `ffprobe`. В `project.json` сохраняются сегмент, текст, параметры TTS, относительный путь аудио и длительность. Перегенерация заменяет только MP3 выбранного сегмента, заново определяет его длительность и обновляет только относящиеся к нему данные. Сбой одного сегмента не останавливает очередь: успешные результаты сохраняются, а проблемный сегмент получает понятный статус с причиной ошибки.

## 5. Дальнейший видеоконвейер

После завершения и проверки этапа 1:

1. Вкладка «Видео»: импорт `.mp4`/`.mkv`, по умолчанию сохранение ссылки на исходный файл, метаданные (имя, длительность, разрешение, FPS) и простой встроенный проигрыватель. Недоступная ссылка требует повторного выбора файла и не подменяется автоматически.
2. Субтитры: импорт `.srt`/`.vtt` или локальная транскрибация Whisper в `analysis/transcript.json` и `analysis/subtitles.srt`.
3. Сцены: PySceneDetect/OpenCV сохраняет таймкоды в `analysis/scenes.json`, не разрезая исходный файл на сотни клипов.
4. Анализ: для сцены собираются диалог, ключевые кадры, визуальное описание, сущности и локальные embeddings.
5. «Подбор кадров»: каждому аудиосегменту подбирается один или несколько отрезков фильма с учётом смысла, субтитров, изображения, персонажей, объектов и хронологии. Хронология — предпочтение, а не жёсткий запрет.
6. Для совпадений показывается confidence; низкоуверенные результаты попадают в список «Требует проверки» и могут быть заменены пользователем.
7. «Монтаж»: простой табличный timeline, где для аудиосегмента можно прослушать аудио, посмотреть видео, изменить таймкод, заменить/добавить/удалить фрагмент. Один аудиосегмент может состоять из нескольких видеофрагментов. Автоматический монтаж добирает последовательные фрагменты до длительности озвучки и подрезает последний; скорость видео не меняется.
8. «Экспорт»: FFmpeg создаёт `export/final.mp4` с настройками разрешения, FPS и MP4. Звук исходного фильма по умолчанию выключен; позднее допускается тихий фоновый режим.

## 6. Сохранение и кэш

Все изменения сохраняются автоматически: текст, аудио, выбранный фильм, анализ, найденные сцены и ручные исправления. `analysis/` хранит транскрипт, субтитры, сцены, embeddings, thumbnails и индекс видео. Повторный запуск использует существующие валидные результаты.

## 7. Границы MVP и порядок работ

Нельзя начинать этапы видео, Whisper, сцен, сопоставления, timeline или экспорта до завершения и проверки этапа 1: создание проекта → загрузка TXT → сегментация → просмотр/объединение/разделение сегментов → Edge TTS → MP3 → длительности → `project.json`.

Конечная цель MVP — позволить пользователю создать проект, озвучить сценарий, добавить фильм, проанализировать его, подобрать кадры, проверить сомнительные совпадения и получить `export/final.mp4`.

## 8. Уточнённые правила поведения

- Новый проект создаётся только после выбора пользователем его папки и названия в диалоге.
- Сегменты — единственный актуальный сценарий после их ручного редактирования; основной текст восстанавливается из сегментов.
- Пересегментация требует подтверждения и не расходует ресурсы на повторное создание актуальных совпадающих MP3.
- Массовая озвучка обрабатывает только отсутствующие и устаревшие сегменты; полная перегенерация — отдельное подтверждаемое действие.
- Ошибка озвучки одного сегмента не отменяет результаты остальных сегментов.
- Исходный фильм по умолчанию хранится как ссылка; её недоступность требует действий пользователя.
- Длительность автоматически подобранного видео равна длительности озвучки без изменения скорости ролика.
