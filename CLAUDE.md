# Инструкции для Claude и совместимых агентов

Следуйте правилам из [AGENTS.md](AGENTS.md). Этот файл намеренно сохраняет те же общие инструкции, чтобы все агенты работали одинаково.

Перед серьёзной задачей прочитайте `AGENTS.md`, `PRD.md`, `CHECKLIST.md`, `TASKS.md` и относящиеся к задаче документы в `docs/`. Пользователь описывает ожидаемое поведение; агент самостоятельно выбирает техническую реализацию и проверяет её до завершения работы.

Проект — локальное Python desktop-приложение. Не добавляйте web/backend, облачные сервисы, аккаунты, платежи или платные API без прямого продуктового требования.
